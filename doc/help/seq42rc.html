MIDI CONTROL

  • MIDI control is available for transport control, recording, and [8] Playlist Mode adjustment.
  • The implementation follows the original seq24 method with minor modifications.
  • Transport control supports start, stop, fast forward, rewind, and beginning of song.
  • For new users, the file is created after quitting the program for the first time.
  • All transport controls are channel specific.

MIDI channels are numbered 0 to 15 in the configuration. Seq42 displays channels 1 to 16 in the UI (offset by -1 when setting values).

MIDI message values

Note On              = 144 + channel (0 to 15)
Note Off             = 128 + channel (0 to 15)
Control Code (CC)    = 178 + channel (0 to 15)

Examples

Example: Set play to toggle start/stop with note C8 (MIDI note 108) on channel 1; start-only with A#7 (106); stop-only with A7 (105): 

# start playing (toggle, start, stop)
0 [1 0 144 108   0 127] [1 0 144 106   0 127] [1 0 144 105   0 127]

Record group: toggles recording on/off for all sequences with an open sequence editor. When recording, only start/stop and record are available, and their events are not passed thru or recorded. Example: set record toggle with A0 (note 21): 

# record
2 [0 0   0   0   0   0] [1 0 144  21   0 127] [0 0   0   0   0   0]

Fast forward example: note-on (144) B7 (107) when pressed, stop on key release note-off (128): 

# fast forward (forward, forward, stop)
3 [0 0   0   0   0   0] [1 0 144 107   0 127] [1 0 128 107   0 127]

Beginning of song moves transport to the beginning of the song or the left (L) grid marker. Example uses A#7 (106): 

# beginning of song
5 [0 0   0   0   0   0] [1 0 144 106   0 127] [0 0   0   0   0   0]

Playlist MIDI control is only active when transport is stopped. You can select while running, but the file will not load until the sequencer stops. The file list starts at 1 and values are range-checked. Toggle group can set by CC value; on group for next; off group for previous. Example: playlist adjust by CC #7; next=A0 (21); previous=A#0 (22): 

6 [1 0 178   7   1 127] [1 0 144  21   0 127] [1 0 144  22   0 127]

[manual-alsa-ports]

  • Set to 1 to expose ALSA ports to JACK.
  • Set to 0 for manual ALSA connections from seq42.
  • No effect if using the JACK MIDI backend.

[vertical-zoom-sequence]

  • Sets default vertical zoom for the sequence editor.

[vertical-zoom-song]

  • Sets default vertical zoom for the song editor tracks on the [3] Main Window.

[horizontal-zoom-song]

  • Sets default horizontal zoom for the song editor tracks on the [3] Main Window.
